# vrinda-store-sales-dashboard-excel
An interactive Excel Sales Dashboard built using Pivot Tables, Pivot Charts, Slicers, and Data Visualization techniques. The dashboard analyzes sales performance, order status, customer demographics, top-performing states, and sales channels to generate actionable business insights.

📊 **Vrinda Store Sales Dashboard (Excel)**

This project presents an interactive sales dashboard created in Microsoft Excel to analyze the 2022 sales performance of Vrinda Store.

**Key Features**
📈 Monthly Sales & Order Trend Analysis
👩‍💼 Sales Distribution by Gender
📦 Order Status Analysis (Delivered, Returned, Cancelled, Refunded)
🏆 Top 5 Performing States
👥 Customer Age vs Gender Analysis
🛒 Orders by Sales Channel (Amazon, Flipkart, Myntra, Ajio, etc.)
🎛️ Interactive Slicers for Month, Channel, and Category Filtering
